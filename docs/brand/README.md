# Hot Eats brand and marketing kit

**Hot Eats is a configurable website kit for independent restaurants and the web partners who build for them.** Its job is to help guests find the menu, check the right hours and location, and take the next step. The campaign line is **Make it easy to come in.**

This is the proposed product identity and pilot launch package for owner review, dated November 12, 2026. The master repository contains the working website kit. Lucyd and the other preset businesses are illustrative.

## What to approve first

1. Confirm the name and descriptor **Hot Eats · Restaurant website kit** as the working public identity. Complete name, domain, and handle checks before external rollout.
2. Choose a pilot restaurant with a named content owner and a web operator. Walk through its menu, location, hours, and configured next action before discussing a broader launch.
3. Decide commercial terms after the pilot establishes setup effort, routine update effort, hosting responsibility, and the support a restaurant needs.

Start each prospect conversation with one real guest task and one maintenance task. Use the local demo to show the flow, then use the pilot to learn what can credibly become a public claim.
